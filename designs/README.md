# Дизайни для сайту

Тут лежать зображення листів, які сайт показує в слайдері «Листи, які ми зробили» і в макеті телефона на першому екрані.

## Що зараз у папці

Шість прикладів (`example-01…06`). Це оригінальні макети з вигаданими брендами: Velour Skin, Kettle & Crane, Maren, Halden Outdoor, Oda Ceramics, Linnea. Фото в них взяті з Unsplash, ліцензія дозволяє безкоштовне комерційне використання: https://unsplash.com/license

Коли з'являться ваші справжні роботи, замініть приклади на них.

## Як додати дизайн

1. Завантажте зображення листа в цю папку (`.jpg`, `.png` або `.webp`, ширина 600–1200 px, висота будь-яка).
2. Допишіть його в `designs.json`:

```json
{ "file": "07-my-brand.jpg", "brand": "My Brand", "title": "Назва кампанії" }
```

3. Через хвилину-дві після публікації дизайн з'явиться в кінці слайдера.

Перші шість карток прописані прямо в `index.html` (так сторінка швидше відкривається). Щоб замінити один із прикладів, змініть шлях до картинки й підписи там або попросіть Claude.
