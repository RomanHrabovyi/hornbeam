# Дизайни для сайту

Сюди завантажуйте зображення листів, які мають з'явитися на сайті в блоці «Наші роботи» і в банері першого екрана.

## Як додати дизайн

1. Відкрийте папку `designs` у репозиторії на GitHub → **Add file → Upload files**.
2. Перетягніть зображення (`.jpg`, `.png`, `.webp`) і натисніть **Commit changes**.
3. За хвилину-дві після публікації дизайн з'явиться на сайті сам.

Сайт показує лише **верх листа (хедер)** у картці 3:4. Відвідувач бачить решту, коли наводить курсор (лист плавно прокручується), або повністю — коли натискає на картку.

## Поради до файлів

- Ширина 600–1200 px, будь-яка висота. Довгий лист — нормально.
- Назва файлу стає підписом: `01-lumen-skin-launch.jpg` → «Lumen skin launch». Число на початку задає порядок.
- Файли, що починаються з `example-`, позначені на сайті як «Приклад». Це заглушки — видаліть їх, коли додасте свої роботи.
- Перші три дизайни йдуть і в банер першого екрана.

## Свої підписи (необов'язково)

У `designs.json` можна задати бренд і назву для конкретного файлу:

```json
{
  "items": [
    { "file": "01-lumen-skin-launch.jpg", "brand": "Lumen Skin", "title": "Запуск нового серуму" }
  ]
}
```

Файли, яких немає в `designs.json`, однаково показуються — з підписом із назви файлу.
